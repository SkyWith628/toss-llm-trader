# 설계: 3x 인버스 페어 + 기댓값 게이트 트리거

> 상태: **설계 확정, 구현 대기** · 작성 2026-08-21 · 대상 브랜치 `feat/realtime-circuit-breaker`
> 선행: 실시간 서킷브레이커 · 진입 LLM화(개장/장중 타이밍) · 트레일링 스톱 · 평가 하네스(모두 구현됨)

## 1. 요구사항 (한 문장)

인버스 관계인 **3x 레버리지 ETF 페어**(예: SOXL/SOXS)에서, **LLM이 방향·비중을 결정**하되 **기댓값이 양(+)일 때만 진입**하고, 청산 임계는 **진입 시점에 확정된 뒤 결정론적으로** 발동한다.

## 2. 왜 이 설계인가 (배경)

- **long-only로 양방향**: 공매도 불가 제약 아래, SOXL(3x 롱)·SOXS(3x 숏)에 비중만 배분하면 매수만으로 강세/약세를 표현. 강세=SOXL, 약세=SOXS, 무확신=현금.
- **3x는 장중에만 쓰면 안전**: 레버리지 ETF의 변동성 붕괴(daily reset)는 **여러 날 보유** 현상. 당일 진입→당일 청산이라 장중엔 거의 선형 → decay 회피.
- **데이터 희소 완화**: 3x는 장중 ±1%가 흔해 서킷/트레일 발동이 잦음 → 평가 시행당 신호가 풍부.
- **역할 분배 유지**: universe(페어)=사람, 비중·방향=LLM, 출구=결정론 코드. 기존 원칙 그대로.

## 3. 핵심 설계 결정 + Trade-off

| 결정 | 선택 | 대안 | Trade-off / 이유 |
|---|---|---|---|
| 기댓값의 위치 | **진입 게이트**(E>0일 때만 진입) | exit를 기댓값으로 발동 | exit를 LLM 기댓값에 걸면 **비결정적 청산**이 부활(우리가 제거한 위험). 진입만 게이트, 청산은 결정론 유지 |
| 청산 임계 출처 | 진입 시 LLM 값(g, ℓ)을 **클램프해 고정** | 고정 상수 임계 | 트리거가 기댓값/뷰를 반영하되, 하루 동안은 **결정론**. LLM 미보정 위험은 상·하한 클램프로 캡 |
| 페어 보유 | **상호배타**(한 번에 한 방향) | 양쪽 동시 보유 | 둘 다 들면 상쇄+수수료·decay 손실. 무확신은 현금이 중립 |
| 3x 임계 | ETF 기준 **넓게 재보정** + 슬리피지 상향 | 기초자산 기준 환산 | 구현 단순(ETF 시세만 사용). 기초자산 환산은 후속 |

## 4. 수학

기호: `p`=LLM 상승/방향 확신(0~1), `g`=목표 수익(익절 폭, >0), `ℓ`=허용 손절 폭(>0).

**기댓값(진입 게이트):**
```
E = p·g − (1−p)·ℓ
진입 조건:  E ≥ E_min   (E_min ≥ 0, 기본 0; 거래비용 여유를 두려면 +값)
```
`E < E_min`이면 신호를 비워 **대기**(기존 "빈 결정=대기" 메커니즘 재사용).

**청산 임계 유도(진입 시 1회 확정, 이후 고정):**
```
take_profit = clamp(g,  TP_min, TP_max)      # 예: [+2%, +8%]
stop_loss   = −clamp(ℓ, SL_min, SL_max)      # 예: [1%, 4%] → 음수로
```
확정 후 서킷브레이커는 지난 세션의 통합 트리거로 결정론 판정:
```
exit if  r_t ≥ take_profit  ∨  r_t ≤ stop_loss  ∨  (M_t ≥ a ∧ r_t ≤ M_t − δ)
```
`r_t`=당일 시작자산 대비 수익률, `M_t`=장중 고점 수익률, `δ`=트레일링 폭, `a`=무장 임계.

**상호배타(가드레일):** 페어 `{L, S}`에 대해 `w_L, w_S` 중 작은 쪽을 0으로.
```
if w_L ≥ w_S:  w_S ← 0   else:  w_L ← 0
```

## 5. 변경점 (구현 시)

- `src/strategy/llm_agent/decision_tool.py`: positions 스키마에 `target`(g)·`stop`(ℓ) 필드 추가. `confidence`(p)는 이미 있음.
- `src/strategy/llm_agent/prompts.py`: 페어·3x·기댓값을 설명하는 프롬프트(진입=E>0, 한 방향만, g/ℓ 제시 요구).
- **신규** `src/strategy/pair_gate.py`: `expectancy(p,g,ℓ)`, 상호배타 후처리, 임계 클램프 — 순수 함수.
- `src/runtime/orchestrator.py`: 진입 시 결정에서 (g, ℓ)를 받아 `risk`의 임계를 확정 주입. (현재 임계는 생성 시 고정 → **진입 시 재설정** 훅 필요: `DayRiskManager.set_thresholds(tp, sl)` 추가 or anchor에 인자.)
- `src/execution/paper_broker.py`: 레버리지용 `slippage` 상향(구성값).
- `src/experiment/eval_harness.py`: 변형에 "SOXL/SOXS 페어 + 기댓값게이트" 추가.

## 6. 테스트 포인트

- `expectancy`: p·g−(1−p)·ℓ 정확 · 경계(E=0) 처리.
- 상호배타: 두 비중 중 작은 쪽 0 · 동률 처리 · 한쪽만 있을 때 무변.
- 임계 클램프: g/ℓ가 범위 밖일 때 상·하한으로 · 정상 범위는 그대로.
- 게이트: E<E_min이면 빈 신호(대기) · E≥E_min이면 진입.
- 동적 임계 주입: 진입 후 서킷브레이커가 **그 날 확정 임계**로 발동(결정론).
- 하네스: SOXL/SOXS 페어에서 결정론 변형 vs 기댓값게이트 비교.

## 7. 미결정 / 리스크 (구현 전 확정 필요)

- **3x 임계 값**: TP/SL 범위(예 익절 [2%,8%], 손절 [1%,4%])는 SOXL/SOXS 1분봉을 하네스로 먼저 관찰해 정한다(옵션 3 "데이터 감각" 선행 권장).
- **슬리피지**: 레버리지 ETF 실제 스프레드 확인 후 값 결정(0.05%는 과소 가능).
- **LLM 확률 미보정**: 초기엔 E_min에 여유(+)를 둬 보수적으로. 사후에 실현 승률 vs 주장 p를 비교(캘리브레이션 로깅).
- **decay 잔여**: 장중이라 작지만, 종가 근접 미청산 포지션은 익일 갭·리셋 위험 → 폐장 강제청산 확인(현재 서킷+폐장 결산으로 커버되나 명시 필요).

## 8. 개선 방향 (후속)

- 기초자산(SOXX) 기준 수익률로 임계 환산(3x 노이즈 정규화).
- 여러 페어 로테이션(TQQQ/SQQQ, SPXL/SPXS) — 단 universe는 여전히 사람이 고정.
- 캘리브레이션 기반 E_min 자동 조정(주장 p의 신뢰도 학습).
